# るう（Luu）試作版 v0.1

メンタルセルフケア × 育成ゲーム「るう」の、ブラウザで動く試作品です。
企画書 v1.0 の P0（試作に必須）を実装しています。スマホ縦画面（390×844前後）向けです。

## 起動手順

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に本番用ファイルを出力
npm run preview  # ビルド結果の確認
```

Node.js 18 以上を想定しています。

## フォルダ構成

```
src/
  config.ts          … 仮の数値（ポイント・確率・価格・閾値）をすべて集めた設定ファイル
  types.ts           … データモデル（企画書13章をもとに一部拡張）
  data/items.ts      … アイテム定義（家具・衣装・おもちゃ・収集品）、記念プレゼント
  data/content.ts    … 文言（気分の返事、おすすめ、冒険の物語、セリフ）
  game/logic.ts      … ゲームロジック（星・親密度・成長・性格・冒険抽選・二重付与防止）
  game/store.tsx     … 状態管理と localStorage への保存
  screens/           … おへや／こころ／きろく／おみせ／ぼうけん／オンボーディング
  sheets/            … 気分・呼吸・日記・タスク・散歩・冒険結果・着せ替え・模様替え・設定など
public/assets/       … 画像アセット置き場（下記）
```

## 画像アセット（public/assets/）

いただいた企画書画像から切り出したものです。

| ファイル | 内容 |
|---|---|
| room_day.jpg | 「初期のお部屋」からるうと見出しを消した背景 |
| room_night.jpg | 上の背景を夜の色調にし、窓を「夜のイメージ」の夜空に差し替えたもの |
| room_sleep.jpg | 「夜のイメージ」（るうがベッドで眠っている）。睡眠中に使用 |
| sit / walk / pet .webp | 「るうの基本アクション」から切り抜き（背景透過） |
| ureshii, tereru, nemunemu, bikkuri, kutsurogi, kangae, shonbori | 表情バリエーション |
| d_* | 日常の動き（歩く・跳ねる・回る・のびる・寝る） |
| g_* | 成長シートの基本の動き・表情 |
| p_* | 性格バリエーション（甘えん坊・元気・のんびり） |
| o_*, c_* | 着せ替え（パーカー・レインコート・ベレー・マフラー・くまフード、リボンベレー・さくらずきん・きょうりゅうフード） |
| avatar.webp | ヘッダー用アイコン |

`src/data/sprites.json` に各画像のサイズを記録しています。すべて同じ縮尺（座ったるうの高さ＝292px）にそろえてあるので、
差し替えるときも同じ縮尺で書き出せば位置・大きさが崩れません。

**原画が無いもの**：家具・おもちゃ・収集品は絵文字の仮アイコンで表示しています（`ItemDef.icon`）。
ベッド・ラグの色違いは原画に色を重ねて表現しています。

## 開発者メニュー

設定（右上の⚙︎）→ 一番下の「るう 試作版 v0.1」を5回タップすると表示されます（一般向けUIには出ません）。

- 星 +100、ふれあい日数 +1、Stage2〜4へ、親密度 +50／Lv5へ、性格ポイント +10
- 時刻を +8時間（翌朝を模擬）／+1日／現在に戻す
- 次の冒険のレア度を固定、シークレット確定

## 実装した主なルール

- 1日の区切りは朝4時（`DAY_START_HOUR`）
- 星：気分（1日初回）+5、タスク +10（1日3件まで）、呼吸・日記・運動 各+10（1日1回）、睡眠 +10。セルフケア関連は1日50まで。冒険・重複交換は別枠
- 親密度：その日最初のケア +10、遊ぶ +5、ごはん +3、なでる +2（仮）、睡眠 +5。各1日1回。下がらない
- 成長：ふれあい日数（1日上限1・後退なし）で4段階。Stage2・3・4で記念プレゼント
- 性格：遊び方・なでる・初めてのおもちゃでポイント加算（1日上限6）。気分や睡眠では変化しない
- 冒険：「おやすみ」→「おはよう」で1晩1回。行き先はStageに応じて自動抽選、セッションIDを種にした決定論的な乱数。30回シークレットが出なければ次は確定。睡眠時刻を編集しても再抽選しない。同じ日に何度寝ても冒険は1回
- 重複アイテムは「保管」か「星に交換」を選べる（自動交換なし）。図鑑の記録は消えない
- 気分・睡眠・未達成によるペナルティなし。ストリークなし
- 記録はすべて端末内（localStorage）。外部送信なし。設定から全消去できる

## v0.4 で追加したもの

- 成長ペース：こども4日目／成長期25日目／おとな60日目（`STAGE_DAYS`）
- なかまたち（切り替え式）：おとなになると3つのたまごから1つ選び、「おやすみ」3晩で色違いのるうが生まれる。
  ヘッダーのるうをタップすると切り替え。成長・親密度・性格・服・みつけたもの帳は1匹ずつ、星・アイテム・部屋は共有
- 色違い（`src/data/colors.ts`）：耳の色だけをブラウザ内で塗り替え（`src/recolor.ts`）。色ごとの原画が届いたら差し替える
- 冒険：その子の色シリーズ（カーテン・ラグ・ふとん・収集品）と季節限定（試作は秋のみ）が一定の確率で出る
- 月1回のふりかえり（るうからの手紙）、演出をひかえめにする設定、状況に合わせたセリフ、引き継ぎコード

## 未実装・制限事項

- P1の3機能（ガイド付き瞑想・セルフコンパッション・人とのつながり）は「準備中」表示
- 衣装は原画が全身コーデのため1つずつ着る形。帽子・首元・洋服の重ね着は部位別の差分画像が必要
- 衣装を着ている間は、リアクションを表情差分ではなく動き（揺れ・跳ねる）で表現
- 家具・おもちゃ・収集品の絵は仮アイコン
- 部屋の背景は原画からるうを消して作ったため、るうが小さい時期（Stage1）はラグ中央が少しぼやけて見える。
  可能なら「るうがいない初期のお部屋」の原画をもらえると綺麗になる
- 「るうプラス」はデモ切替のみ（決済なし）。季節プレゼントは秋のみ用意
- 端末のブラウザ内保存のため、別の端末・ブラウザとは同期しない
- フォントは Google Fonts（Zen Maru Gothic）を読み込み。オフラインでは端末の標準フォントになる
