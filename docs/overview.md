# るう（Luu）アプリ概要

> ほかのAIや協力者に、るうのアプリを説明するための資料。2026年11月時点の内容。

## ひとことで

垂れ耳うさぎの「るう」と暮らしながら、気分の記録や小さな習慣などのセルフケアをすると、るうが育っていくアプリ。夜「おやすみ」を押すと、るうが夢の中で冒険して、朝おみやげを持って帰ってくる。

- 試作版（ホーム画面に置けるWebアプリ）：https://minamina33.github.io/Luuapp/
- キャッチコピー：「きょうも、ちいさく、いっしょに。」

## だれのためのアプリか

- 主なターゲット：仕事終わりに疲れている、20〜30代の働く女性（男性も使えるようにする）
- 想定ユーザー像：26歳・会社員・ひとり暮らし。帰るとぐったりして自分のケアは後回し。習慣アプリは、できない日が続くとやめてしまった。気分の落ちこみに、あとから気づく

## 解決したいこと

| いまの困りごと | るうでどうなるか |
|---|---|
| 疲れて、自分のケアが後回しになる | 気分の記録は1回約30秒。寝る前1分で自分をいたわれる |
| 習慣アプリは、休むとやめてしまう | 休んでも、るうは弱らない。成長も戻らない |
| 気分の落ちこみに、あとで気づく | 「きろく」で気分と睡眠の波をふり返れる |

## おもな機能

- **おへや**：るうが暮らす部屋。タップしてふれあう、ごはん・あそび、きせかえ・もようがえ
- **ケア**：気分の記録（5段階＋関係すること＋メモ）、今日の習慣（3〜5個）、呼吸法、日記、散歩・おでかけ、睡眠の記録（おやすみ／おはよう）
- **きろく**：気分・睡眠・日記のふり返り、月ごとの「るうからの手紙」
- **ぼうけん**：夜の冒険の結果、図鑑（収集品）、エリア（花の森・月あかりの湖・星空の丘）、星座帳
- **おみせ**：セルフケアと冒険でたまる「星」で家具・衣装・おもちゃと交換
- **成長**：あかちゃん → こども → … → おとな（約60日・ひと季節）。育て切ったら色違いのるうを迎えられる
- **安全**：つらいときの相談先（24時間の窓口）をいつでも開ける。日記に命にかかわる言葉があれば相談先を出す

## 大事にしている方針

1. **罰をつくらない**：できない日があっても、るうは弱らない。責める言い方や「がんばれ」で追いつめる言い方はしない
2. **星はお金で売らない**：星はセルフケアと冒険でだけ手に入る。課金で成長を早くしない
3. **プライバシー**：記録は端末の中だけに保存し、外部に送らない
4. **医療をうたわない**：「治る」「効く」などの表現は使わない
5. **少しずつ出す**：はじめての人に機能を出しすぎない（はじめての1週間は、毎日1つだけ案内する）

## マネタイズ（課金）

基本のセルフケア（記録・習慣・冒険・相談先・引き継ぎ）はずっと無料。お金で買えるのは見た目と楽しさだけ。

| 種類 | 内容 | 価格（仮） |
|---|---|---|
| るうプラス（サブスク） | 毎月の会員アイテム、ひみつの雲の島、テーマプログラム、1か月のふりかえり | 年額4,800円（おすすめ）／月額680円。14日間無料 |
| 限定アイテム | 季節のセット・衣装（見た目だけ） | 1つ120〜480円 |

やらないこと：広告、ガチャ、連続記録の保護の販売、つらい気分の日の課金案内。

## マーケティング（予定）

- るうのInstagramアカウントを中心に、週3投稿（夜21時の「おつかれさま」1枚絵、4コマ・日常、開発の様子）
- 事前登録はGoogleフォームで集め、登録者に限定衣装を配る
- LINEスタンプで、るうのキャラクターを知ってもらう
- 運用はMeta Muse（AIエージェント）に分析や投稿案づくりを手伝ってもらい、投稿は必ず人が承認する

## 技術

- React 18 + TypeScript + Vite。PWA（ホーム画面に追加して使う）
- データは端末のlocalStorageに保存（引き継ぎコードで移行できる）
- iPhoneアプリ化（Capacitor）を準備中
